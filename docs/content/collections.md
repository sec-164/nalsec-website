# コンテンツコレクション

テキストのみのプレビュー用に、Astro のコンテンツコレクションを 3 つ定義している(`src/content.config.ts`)。内容の根拠は `docs/content/inventory.md`、URL は `docs/content/url-structure.md`。

## トップページの画面順

トップページの画面の並び(ヒーロー → series を `order` 順 → services を `order` 順 → 会社情報)は `src/lib/screens.ts` の `getScreens()` だけが決める。トップの各セクションと、右端のセクションナビ(`src/components/SectionNav.astro`。現在の画面を示す縦のインジケーター)・ヘッダーのナビのリンク先(各ナビ項目に属する最初の画面)はすべてここから作る。ナビ項目そのものは `src/data/site.ts` の `nav`。画面を増やすときはコレクションにエントリを足すだけでよく、ヘッダー側の修正は要らない。

## products(`src/content/products/*.md`)

スラッグはファイル名(`xnergy-ph.md` → `/products/xnergy-ph/`)。

| フィールド      | 型                        | 意味                                                                                                                                                                |
| --------------- | ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `title`         | string                    | 表示名(例: Xnergy ワイヤレス充電器 PH)                                                                                                                              |
| `manufacturer`  | string                    | メーカー表記(Xnergy、BSLBATT、VITZROCELL)                                                                                                                           |
| `category`      | `"charger"` / `"battery"` | 分類                                                                                                                                                                |
| `categoryLabel` | string                    | 分類の表示用(充電器 / 電池)                                                                                                                                         |
| `models`        | string[]                  | 型番。なければ `[]`                                                                                                                                                 |
| `applications`  | string[]                  | 用途タグ。製品リストの「市場」に合わせる                                                                                                                            |
| `summary`       | string                    | 製品ページに載せる紹介文。1 行 1 文、改行は `<br>` で表示                                                                                                           |
| `highlights`    | string[](省略可)          | トップページのシリーズ画面に載せる 2〜3 行。同じシリーズの兄弟製品との違いだけを、体言止め・1 行 22 字程度で書く。`summary` と `## 特長` にない事実や数値は入れない |
| `catalog`       | string(省略可)            | `references/` 内のカタログのファイル名                                                                                                                              |
| `order`         | number                    | 一覧での並び順                                                                                                                                                      |

## series(`src/content/series/*.md`)

トップページで 1 画面にまとめる製品のまとまり(シリーズ)。1 エントリ = トップの 1 画面。本文は使わない(空でよい)。

| フィールド      | 型                        | 意味                                                                                       |
| --------------- | ------------------------- | ------------------------------------------------------------------------------------------ |
| `title`         | string                    | シリーズの見出し(例: Xnergy ワイヤレス充電器)                                              |
| `short`         | string(省略可)            | セクションナビ(広い画面)に出す短い名前(例: Xnergy)。メーカー名か最初の語。省略時は `title` |
| `manufacturer`  | string                    | メーカー表記                                                                               |
| `category`      | `"charger"` / `"battery"` | 分類                                                                                       |
| `categoryLabel` | string                    | 分類の表示用(充電器 / 電池)                                                                |
| `lead`          | string                    | シリーズが何かを言う 1 文(体言止め)。所属製品の `summary` と `## 特長` の範囲で書く        |
| `products`      | string[]                  | 所属する製品のスラッグ(products のファイル名)。表示順                                      |
| `order`         | number                    | トップページでの並び順                                                                     |

製品数で表示が変わる: 2 製品は 2 列(スマホは縦積み)、3 製品以上は横長の行を縦に並べる、1 製品は文章 + 画像枠。製品を追加したら、どれかのシリーズの `products` に入れ、兄弟製品の `highlights` も見直す。

## services(`src/content/services/*.md`)

スラッグはファイル名。フィールドは `title`、`short`(省略可。セクションナビに出す短い名前。例: 医療機関向け。省略時は `title`。サービスが 1 件だけの間はグループ名「サービス」を出すので使われない)、`summary`、`targets`(対象。string[])、`order`。

## 本文(Markdown)の書き方

- 製品の本文は `## 特長` → `## 仕様` の順。ほかの節は作らない。`## 概要` と `## 用途` は使わない(`summary` と重複するため)。固有の情報は `## 特長` の箇条書きに短く入れる。
- 仕様はカタログの表を、項目名・値・単位・注記・型番の列・並び順までそのまま写す。丸めない、要約しない、行を落とさない。表が複数あるときは、カタログの表題を `###` の見出しにして 1 表ずつ書く。型番が複数ある表は、型番ごとに列を分けた 1 つの Markdown 表にする。
- 公開しない内容(備考、出典、確認事項、「要確認」の印、編集上のメモ)は書かない。未解決の確認事項は `docs/content/inventory.md` に置く。
- 根拠のない訴求(「最大 70% のコスト削減」など)は載せない。
- BE カタログ 1 ページ目の電話番号の誤記は、どこにも書かない。電話番号は `src/data/site.ts` の値を使う。

## 製品の追加方法

1. `src/content/products/` の既存ファイルをコピーし、`{メーカー}-{シリーズまたは種別}.md` に改名する(スラッグ = ファイル名)。
2. フロントマターを埋める。数値は資料にあるものだけ。資料が無い項目は空にする。
3. 本文を書き換える。
4. `pnpm exec astro sync` と `pnpm check` を通す。

Enatel は掲載保留、資料が無い製品(PBM、Electrovaya、Vitzrocell CR / LFP、BSL フォークリフト・ゴルフカート、IT コンサルテーション)は、資料がそろうまで作らない。

## サイト共通情報

社名・キャッチコピー・住所・電話番号・技術マガジンへのリンクは `src/data/site.ts`(`site`)にある。
