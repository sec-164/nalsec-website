PH シリーズ(「小型ハイパワーワイヤレス充電器」、カタログに NEW 表示)

- 主要スペック: 最大充電電力 1,500W、最大電流 DC60A、エアギャップ 1〜5cm、充電電圧 DC16〜60V。
- 送信ユニット TX18PH: AC 200/230V、最大 10A、335x254x86mm、6.7kg、IP54。送信パッド 335x175x25mm、IP65。
- 受信ユニット RX4803PH: 公称 48V、最大 30A、185x90x47mm、1kg、IP45、通信は GPIO / CAN bus / RS485(Modbus)。受信パッド 218x109x21.5mm、IP65。
- 使用温度 -20〜+40℃。対応電池はリチウムイオン・鉛蓄。
- 特長: 小さな設置面積(スマートフォンよりわずかに大きい)、5cm エアギャップで位置公差が広い、露出接点がなく安全、1 台の送信機で異なる電池を充電、ケーブルの消耗がない。

BE シリーズ(「高出力ワイヤレス充電ソリューション」)

- 主要スペック: 充電電力 9kW、サイズ 20x20cm、最大エアギャップ 7cm、電圧範囲 DC16〜60V、最大電流 DC90A(モジュールごと)、最大スタック電流 270A。
- 送信機 TX30BE-1A00: AC 200〜230V、最大 16A、361x244x91.5mm、7kg、IPX0(屋内用)。送信パッド 400x200x20.7mm、IPX0。
- 受信機: RX2409BE(24V / 最大 90A / 2,400W)、RX4805BE(48V / 最大 50A / 2,500W)、202x231x52mm、3kg、GPIO / CAN bus / Modbus。対応電池はリチウムイオン・鉛蓄・ニッカド等。
- 特長: 9kW の高電力、複数バッテリーに対応、7cm の広いエアギャップ、急速充電、ケーブル不使用でメンテナンスコストと人件費を削減、20 か国以上で使用。「TÜV SÜD CE 安全規制への準拠」の記載あり(証明の裏付けは要確認)。
- 用途(応用例): 倉庫、クリーンルーム、AGV、フォークリフト。
- 注意: PH の寸法図に透かし「CONFIDENTIAL」あり(§6 c)。BE の「9kW」は受信機表(2.4 / 2.5kW)と直接つながらない(要確認)。
