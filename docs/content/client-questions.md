# クライアントへの確認事項(2026-11-08 プレビュー提出時点)

プレビュー: https://nalsec-renewal.pages.dev/
詳細な背景は `inventory.md` §6 と `../../references/research/README.md` を参照。

## A. 取り扱い製品の確定

1. **Enatel**(EcoCharge、ECO9703 / ECO9701、屋外キャビネット、DC Power System)の掲載保留は、いつ・どの条件で解除されるか。現行サイトに残っているページはそのままでよいか。
2. **ESS Energy Warehouse**(現行サイトにあるが製品リストに無い)は今後も扱うか。
3. **Vitzrocell「LFP 電池」**は公式に存在しない。実体は何か(リチウムイオン二次電池 VHC / VLB のことか、記載ミスか)。
4. 製品リストの**「将来」行**(充電器 / 電池 / ソーラパネル / 電子機器 / その他)は、サイトに「今後の取り扱い予定」として載せてよいか、社内メモか。

## B. 資料の提供依頼(ページを作るため・内容を正すため)

5. カタログ・仕様表が無い製品: **PBM 車載 / 定置式、Electrovaya、Vitzrocell CR、BSLBATT フォークリフト向け / ゴルフカート向け**。公式サイトの情報だけで作っているため、日本語カタログかスペック表がほしい。
6. **Vitzrocell ER** の型番表(現行サイトは概要のみ)。公式の呼称は「ER」ではなく SB(ボビン型)/ SW(巻回型)だが、サイト上の呼び方はどうするか。
7. **BSLBATT** の製品は公式 .com ではなく bsl-battery.co.uk / lithium-battery-factory.com に掲載されている。取引先の法人はどれか。ゴルフカート向けの 72V 系はサイト間で定格が食い違うため正式値がほしい。
8. 製品リストの「製品数」(「9 種以上」「多数」など)と公式の型番数が合わない(例: Vitzrocell CR は公式 3 型番に対し「6 種以上」、PBM は「4 種以上」に対し車載 3 シリーズ)。どちらを正とするか。
9. **Xnergy** カタログ(2025-08 版)と公式サイトで数値が異なる箇所(PH の電流・エアギャップ)。最新の確定値はどちらか。PH カタログの誤記 2 か所(「対環境背」「口結無き事」)の正しい語。
10. **Xnergy BE カタログ**に記載の電話番号 03-5431-4799 は誤り(正: 03-5341-4799)。カタログ側の訂正を。

## C. 写真・文章の使用許諾

11. 公式サイト・カタログの**写真や図版を Web に転載してよいか**(Electrovaya と PBM は規約で商用転載を制限。Xnergy PH カタログには「CONFIDENTIAL」の透かし)。メーカー提供の Web 用画像があれば提供を。
12. 現在のプレビュー写真は現行サイトからの暫定流用。**VITZROCELL の写真は Adobe Stock の透かし入りプレビュー**のため差し替え必須。ヒーロー(夜景)を含め、各画面の写真をどうするか(撮り下ろし / ストック購入 / メーカー提供)。
13. メーカー名・型番・ロゴをサイトに掲載してよいか(代理店契約上の制約の有無)。

## D. 文章の確認

14. **医療機関向けコンサルティング**の本文は現行サイトのままで、「2024 年 4 月から始まる」「2021 年中に計画立案」など時制が古い。最新の内容に書き直す素材がほしい。IT 向けコンサルティング(製品リストに記載)の内容も。
15. トップのキャッチコピー「蓄電システム・発電機・産業用電池の販売…IoT システムの構築」のうち、**発電機・IoT システム構築**に対応するページが無い。文言を残すか、ページを作るか。
