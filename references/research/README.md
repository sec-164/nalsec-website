# メーカー公式サイトの調査メモ

製品リスト(クライアント提供)に載るメーカーの公式サイトを 2026-11-08 に調べた記録。カタログ PDF が無い製品について、公式サイトの情報だけでページを作れるかを判定するために使う。情報は WebFetch / WebSearch の要約経由のため、数値は掲載前に原ページで再確認すること。

- 公式サイトの文章・写真・ロゴは転載しない。事実と数値を自分の言葉で書き直して使う。
- 判定基準: ◎=そのままページ化できる / ○=小さな確認事項を残してページ化できる / △=情報が薄く、追加確認が前提 / ×=ページ化できない。
- ページ化の前提(決定済み): カタログの無い製品は仕様表なしで作る。導入文(体言止め)と特長の箇条書きのみ。必要な情報は「何か」「どの車両・用途か」「電圧クラスまたは容量の幅(言葉で)」「具体的な特長 3〜6 点」。
- Enatel は掲載保留。調査メモは再開時のために残す。

## クライアントへの確認(調査で新たに出たもの)

- BSL の対象製品(フォークリフト・ゴルフカート・GSE)は、公式 .com ではなく別ドメイン(bsl-battery.co.uk、lithium-battery-factory.com)に載っている。3 サイトが同一グループか、NALSEC の取引先はどの法人かを確認したい。日本法人らしき表記(BSL NEW ENERGY(JPN))もある。
- PBM のリストは「車載 4 種以上 / 定置 4 種以上」だが、サイトの車載型は 3 シリーズ(HF799 / HF1000 / HF1400)、鉛用充電器は 21 機種、リチウム用は 8 機種。NALSEC の取扱機種はどれか。
- Electrovaya の数値がページ間で食い違う(サイクル寿命 9,000 / 14,000 / 15,000 回、保証 6 / 8 / 10 年、充電 1 / 1.5 時間)。公開する数値の出典をどれにするか。型番の公開もない。
- Vitzrocell の「LFP」は公式に存在しない。意図は公式のリチウムイオン二次電池(VHC / VLB)か、BSL の LFP か、リストの誤記か。
- Vitzrocell の公式呼称は SB / SW(ボビン / 巻き)で「ER」ではない。サイトで「ER」を使い続けるか。取扱型番(リストは 6 種以上)はどれか。CR は公式 3 型番で、リストの 6 種以上と合うか。
- 公式サイトの写真・文章・ロゴの使用許諾。Electrovaya と PBM は規約で商用転載を制限、ほかは許諾が必要と考えられる。許諾を取るか、写真は撮り下ろし・メーカー提供に絞るか。
- Xnergy の日本語公式サイトと国内窓口(代理店)の記載がなく、NALSEC の名前も出ない。取扱代理店として載せる表現をメーカーに確認できるか。
